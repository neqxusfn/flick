# Account safety and fair play

Flick performs a 180° mouse movement from one button press. This is input automation. It does not inject into a game, read game memory, or bypass anti-cheat, but **that does not make it allowed or ban-safe**. Publishers can change their rules and enforcement. The only reliable choice is to check the current rules for the specific game and server before use; do not use Flick where automation is prohibited. Flick's game presets only convert sensitivity to counts.

Examples of official policies to consult:

- [Riot Games third-party applications policy](https://support.riotgames.com/en-us/riot/events/third-party-applications) says applications that take actions for players or give an advantage can be unacceptable and may lead to penalties.
- [Epic Games Fortnite Code of Conduct](https://www.epicgames.com/help/c-34254770/c-33726977/a17233179) prohibits cheating and describes possible penalties. [Epic's third-party software guidance](https://www.epicgames.com/help/c-34254770/c-40491939/a15028164) says it cannot determine whether a specific tool will cause a ban and that Fortnite does not officially support third-party software.
- For games on Steam, review the specific game's rules and server policies. Steam's [Trusted Mode FAQ](https://help.steampowered.com/en/faqs/view/09A0-4879-4353-EF95) covers one class of third-party interactions; it is **not** permission for input automation.

The first-run in-app warning must be acknowledged before enabling. Flick then remains paused until you explicitly enable it. The warning can be reopened from **Account risk** in the main window. This acknowledgment records that you saw the notice; it is not a compatibility or safety guarantee.
