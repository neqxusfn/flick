# Changelog

## 0.1.0 — 2026-10-11

- Initial Windows x64 desktop release: Tauri 2, React, and a native Rust input engine.
- One-button half turns with 0–100 ms duration, direction, fractional count tracking, and optional return on release.
- Mouse side-button, middle-button and keyboard capture; F8 pause/enable hotkey.
- Game sensitivity, distance/DPI, and raw-count calibration; F9 manual-turn measurement.
- Local profiles, optional foreground process matching, tray controls, and optional Windows startup.
- System, light and dark appearance; bundled Inter and Lucide; accessible Settings sheet.
- Sourced Valorant and Fortnite presets. Other requested games omitted pending sufficient primary evidence.
- Windows release pipeline producing an NSIS installer and standalone executable.
- First-use account-risk acknowledgment before enabling, enforced for the window, F8 hotkey, and tray toggle. Permanent safety link in the main window and publisher-policy guidance in the README.
